# 📊 Frontend Mentor - Grid Landing Page Challenge

Welcome to my solution for the [Grid landing page challenge on Frontend Mentor](https://frontendmentor.io). This project focus on masterfully aligning layouts using semantic layouts and complex multi-column grid properties.

## 🔍 Project Overview

### 🚀 The Challenge

The objective of this challenge is to build a responsive statistical dashboard for "Bridge Collective" where elements dynamically rearrange across different screen configurations:
* **Mobile Viewport:** Clear, singular vertical data stack for optimal accessibility.
* **Desktop Viewport:** Transformative 2-column view splitting hero branding items cleanly away from a distinct 2x2 grid framework container.

## 🛠️ Built With

* **Semantic Content Blueprints** - Leveraging tags like `<main>`, `<section>`, and `<footer>` for maximum screen-reader accessibility.
* **CSS Custom properties** - Consolidating HSL parameters globally inside global theme variable roots.
* **CSS Flexbox** - Organically aligning item stacks, headers, and footer components vertically.
* **CSS Grid Systems** - Structuring advanced column structures with responsive fractional spacing properties.
